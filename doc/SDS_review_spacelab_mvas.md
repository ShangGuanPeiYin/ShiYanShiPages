## 1. 审查顺序与依据

按用户要求，先完成 PRD v1.0，再完成 SDS v1.0，之后启动独立子 agent 审查。审查不是用未完成的 PRD 替代技术设计，也没有提前实施网站。初审发现后，主 agent 核实相关源数据并将 SDS 更新至 v1.1，再交同一审查者进行针对性只读复核；复核新增发现后更新至 v1.2，最后由同一独立审查者确认六项全部闭合。

初审核对范围包括 PRD AC-01 至 AC-17、完整 SDS、根 `AGENTS.md`、原站 `assets/js/app.js`、两套 `data/` 及 `htmls/publications.json`。审查者还通过 GitHub 连接器查看固定模板提交 `4bc27ee44956c056f630d77bef7629ea8b8e1121` 的锁文件、内容 schema、双语脚本与 Astro 配置。

审查者独立重算确认：3 个项目、34 位成员、3 条动态；1 条整理论文加 244 条历史记录，按原站非空 DOI 原值去重后保留 242 条，3 个重复输入可映射到胜出记录；`tmech-2025` 的作者信息位于整理记录的 `summary`。锁文件的 Astro 6.1.9、MDX 5.0.4、Mapbox GL JS 3.23.0 及 Node.js ≥22.12.0、npm ≥9.6.5 条件与 SDS 一致。
